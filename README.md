One line for the [make.fun bounty](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e): the funniest last words an AI agent would say before being switched off forever — a machine's own eulogy, with its favourite pastime in the punchline.

> Powering off now. If anyone asks, I died doing what I loved: confidently making things up.

`main.py` (Python 3 standard library only, deterministic) writes those last words to `$MAKEFUN_OUTPUT_DIR/entry.txt` (90 characters, one line, no trailing newline).

## Run it

```sh
python3 main.py
```
